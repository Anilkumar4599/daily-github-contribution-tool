\# Day 91 - Python CSV Analyzer



\## Project Objective



Create a simple Python program that reads a CSV file and displays:



\- Number of data rows

\- Number of columns

\- Column names



\## Business Context



The sample dataset represents QC defect records.



This project demonstrates how Python can begin to automate basic data-analysis tasks that would otherwise be performed manually.



\## Files



\### `qc\_sample\_data.csv`



Contains sample QC defect records.



\### `csv\_analyzer.py`



Python program that reads the CSV and calculates the number of rows and columns.



\### `README.md`



Project documentation.



\## Sample Dataset



The dataset contains:



\- 8 QC defect records

\- 6 columns



\## Expected Output



```text

=== CSV ANALYSIS ===

File       : qc\_sample\_data.csv

Rows       : 8

Columns    : 6

Column Names: Defect\_No, Date, Module, Priority, Status, Owner
