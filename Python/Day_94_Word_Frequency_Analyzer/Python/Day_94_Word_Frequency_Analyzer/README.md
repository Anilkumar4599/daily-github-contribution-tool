\# Day 94 - Word Frequency Analyzer



\## Objective



Create a Python program that reads a text file and counts the frequency of each word.



\## Business Context



Word-frequency analysis can be useful when processing unstructured business information such as:



\- QC reports

\- Service reports

\- Procurement notes

\- Email text

\- Incident descriptions

\- Technical logs



The objective is to identify which words occur most frequently.
