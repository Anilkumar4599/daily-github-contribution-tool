\# AWS Beginner Services Cheat Sheet



\## Purpose



This project provides a simple beginner-friendly reference for commonly used AWS services.



\## Main Topics



\- EC2 - Compute

\- S3 - Storage

\- RDS - Database

\- VPC - Networking

\- IAM - Access control

\- CloudWatch - Monitoring

\- SNS - Notifications

\- Lambda - Serverless computing

\- ELB - Load balancing

\- Auto Scaling - Automatic capacity

\- Route 53 - DNS

\- CloudFront - Content delivery

\- ECR - Container images

\- ECS - Containers

\- EKS - Kubernetes



\## Validation



The cheat sheet includes five simple input-validation test cases.



Each test checks whether a business requirement maps to the appropriate AWS service.



\## Learning Objective



Understand the purpose of common AWS services before moving into hands-on AWS and DevOps implementation.
