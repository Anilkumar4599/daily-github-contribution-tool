\# Day 114 — Reusable RCTO Prompt Template



\## Project Overview



This project provides a reusable prompt framework based on Role, Context, Task, and Output (RCTO).



\## Objectives



\- Structure AI instructions consistently.

\- Improve the clarity of business analysis tasks.

\- Reduce unsupported assumptions.

\- Standardise report formats.

\- Validate outputs using example inputs and test cases.



\## Project Files



\- `RCTO\_Prompt\_Template.md` — Reusable template, procurement example, expected output, and three test cases.

\- `README.md` — Project overview and usage guide.



\## How to Use



1\. Select the appropriate professional role.

2\. Explain the business context and data available.

3\. Specify the task in clear steps.

4\. Define the required output format.

5\. Provide the relevant data.

6\. Validate calculations and assumptions.

7\. Review recommended actions before using them in business decisions.



\## Test Cases



1\. Validate overdue-day calculations.

2\. Confirm delivered orders are excluded from open overdue lists.

3\. Confirm missing due dates are flagged.
