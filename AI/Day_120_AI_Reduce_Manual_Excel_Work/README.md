\# Day 120 — AI to Reduce Manual Excel Work



\## Project Overview



This project documents five practical ways Artificial Intelligence can reduce repetitive Excel work in Procurement, Vendor Management, Quality Control, Inventory, and Management Reporting.



\## Five Use Cases



1\. Excel Data Cleaning and Validation

2\. Purchase Order Follow-Up and Overdue Analysis

3\. Vendor Performance Analysis

4\. QC Defect Classification and Analysis

5\. Automated Management Summary from Excel Data



\## Key Learning



\- Understanding where AI can assist Excel users.

\- Using AI prompts for practical business tasks.

\- Combining Excel formulas with AI analysis.

\- Validating AI-generated reports.

\- Avoiding fabricated data and unsupported conclusions.
