\# QC Pareto Analysis — ATM Surveillance Devices



\## Project Overview



This project demonstrates a sample Pareto analysis for defects identified

during QC inspection of ATM surveillance devices.



The objective is to identify the defect categories contributing the largest

share of total defects and help QC management prioritize corrective actions.



\## Business Purpose



Pareto analysis can help QC management:



\- Identify the most frequent defect categories.

\- Prioritize Root Cause Analysis (RCA).

\- Focus corrective and preventive actions.

\- Identify recurring hardware or network problems.

\- Support supplier and service performance reviews.

\- Improve overall product quality.



\## Sample Data



The project uses a small hypothetical dataset containing 50 sample defects

across six defect categories.



The top three categories are:



1\. Camera No Video — 18 defects

2\. Router / Network Issue — 12 defects

3\. Power Failure — 8 defects



Together, these three categories represent 76% of the total sample defects.



\## Input Validation Rules



Before performing the Pareto calculation:



\- Defect category must not be blank.

\- Defect count must be numeric.

\- Defect count must be a whole number.

\- Defect count cannot be negative.

\- Total defect count must be greater than zero.



\## QA Validation



The analysis was reviewed using the following checks:



\- Total defect count = 50

\- Total percentage = 100%

\- Final cumulative percentage = 100%

\- Top three defect categories = 76%



All sample validation checks passed.



\## Key Management Finding



Camera No Video, Router / Network Issue, and Power Failure account for

76% of the sample defects.



Therefore, these three categories should receive priority for:



\- Root Cause Analysis

\- Corrective Action

\- Preventive Action

\- Supplier review

\- Recurrence monitoring
