

\# Day 139 – QC KPI Definition Document



\## Project Objective

Create a standardized QC KPI definition document for ATM E-Surveillance device quality monitoring.



\## Project Files

\- `QC\_KPI\_Definitions.md` – Seven QC KPI definitions, formulas, interpretation and reporting frequency.

\- `sample\_qc\_kpi\_input.csv` – Example input data for KPI calculations.

\- `README.md` – Project overview and usage.



\## KPIs Covered

1\. Inspection Coverage

2\. First Pass Yield (FPY)

3\. First Pass Failure Rate

4\. Defective Unit Rate

5\. Rework Rate

6\. Rework Closure Rate

7\. Recurring Defect Incident Rate
