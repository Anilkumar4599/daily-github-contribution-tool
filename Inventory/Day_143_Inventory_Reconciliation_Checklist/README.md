

\# Day 143 - Inventory Reconciliation Checklist



\## 1. Project Overview



Created an Inventory Reconciliation Checklist to verify physical stock against inventory system records.



The project includes a practical checklist and sample test cases covering matched stock, shortages, excess stock, and system balance mismatches.



\## 2. Project Files



\- `inventory\_reconciliation\_checklist.md` - Inventory verification and reconciliation checklist.

\- `sample\_reconciliation\_test\_cases.csv` - Four sample test cases.

\- `README.md` - Project documentation.

\- `Day\_143\_Git\_Commands.txt` - Git command history.



\## 3. Reconciliation Formula



Expected Closing Stock = Opening Stock + Stock-In - Stock-Out



Physical Variance = Physical Stock - System Stock



\## 4. Test Case Summary



| Test ID | Scenario | Expected Result |

|---|---|---|

| TC-001 | Physical stock matches system stock | Matched |

| TC-002 | Physical stock is lower | Physical Shortage |

| TC-003 | Physical stock is higher | Physical Excess |

| TC-004 | Calculated closing differs from recorded system stock | System Balance Mismatch |



\## 5. Business Benefits



\- Improves inventory accuracy.

\- Identifies stock shortages and excess quantities.

\- Helps detect missing or duplicate transactions.

\- Supports corrective action and management approval.

\- Improves procurement and warehouse controls.

\- Provides a documented reconciliation process.



\## 6. Assumptions



1\. Sample data is illustrative.

2\. All quantities are measured in units.

3\. Opening stock represents the beginning balance.

4\. All stock movements should be recorded.

5\. Physical counts are performed on the reconciliation date.

6\. Inventory adjustments require approval.
