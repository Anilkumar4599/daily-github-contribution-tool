\# AI Learning \& Technical Skills Development Journey



\## Project Overview



This project documents my structured learning journey in:



\- Quality Control (QC)

\- Procurement \& Inventory

\- Power BI

\- AWS

\- Git \& GitHub

\- DevOps

\- AI and Automation



The objective is to convert practical business experience into structured technical knowledge and gradually build hands-on skills.



\---



\## Learning Approach



The learning process follows:



Understand → Document → Validate → Practice → Test → Measure → Improve → Automate



Each daily task is tracked using a GitHub-based contribution workflow.

Input Validation



Before accepting data for analysis, the following basic checks should be performed:



Required fields should not be empty.

Numeric fields should contain valid numbers.

Quantities should not be negative unless specifically allowed.

Dates should use a valid date format.

Status values should come from an approved list.

Duplicate records should be checked.

Invalid records should be identified before analysis.
