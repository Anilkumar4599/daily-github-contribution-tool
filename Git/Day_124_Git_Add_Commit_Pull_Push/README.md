\# Day 124 – Git Add, Commit, Pull and Push



\## Objective

Understand the difference between four essential Git commands and document their practical usage.



\## Commands Covered

1\. `git add` – Stage selected changes.

2\. `git commit` – Save staged changes locally.

3\. `git pull` – Fetch and integrate remote changes.

4\. `git push` – Upload local commits to the remote repository.



\## Project Files

\- `GIT\_ADD\_COMMIT\_PULL\_PUSH.md`

\- `README.md`



\## Practical Validation

Four test cases are included:

\- Check repository status.

\- Check commit history.

\- Check remote configuration.

\- Check current branch.



\## Learning Outcome

Understand the daily Git workflow and use the correct command at the correct stage of development.
