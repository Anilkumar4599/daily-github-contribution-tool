\# Day 125 – CONTRIBUTING.md



\## Objective

Create contribution guidelines for the Daily GitHub Contribution Tool repository.



\## Main File

`CONTRIBUTING.md`



\## Topics Covered

\- Getting started

\- Branching guidelines

\- File and folder organization

\- Coding and documentation standards

\- Testing guidelines

\- Commit message conventions

\- Pull request process

\- Repository safety rules



\## Validation

Review the document for:

1\. Correct file name.

2\. Clear contribution instructions.

3\. Relevant repository folder names.

4\. Practical Git workflow.

5\. Simple and understandable language.



\## Learning Outcome

Understand how to guide other developers and contributors when they work on a GitHub repository.
