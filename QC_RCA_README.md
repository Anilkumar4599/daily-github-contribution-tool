\# QC RCA Template — README



\## Project Overview



This project provides a structured Root-Cause Analysis (RCA) template

for QC defect investigation.



The template is designed to help QC teams document:



\- Problem statement

\- Evidence

\- Immediate cause

\- Root cause

\- Five-Why analysis

\- Corrective action

\- Preventive action

\- Verification

\- Closure



\## Business Purpose



A structured RCA process helps management:



\- Reduce recurring defects

\- Identify true root causes

\- Improve corrective actions

\- Track preventive actions

\- Verify effectiveness

\- Improve product quality



\## Input Validation



Before RCA begins, verify:



\- Defect number

\- Defect description

\- Severity

\- Device

\- Reproduction procedure

\- Evidence/logs

\- Failure frequency

\- Ownership



Missing information must not be assumed.



Use:



\*\*Unknown / Information Required\*\*



when evidence is unavailable.



\## Key Principle



\*\*No evidence = No confirmed root cause.\*\*



A possible cause is only a hypothesis until it is supported by technical

evidence and validation.
