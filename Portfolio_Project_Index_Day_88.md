\# 3. Project Status Definitions



The following status definitions are used to keep the portfolio accurate.



\### Hands-on



The project includes actual tool/software usage or practical execution.



\### Completed



The documentation or analysis requested for the project has been completed.



\### Documentation



The work is primarily conceptual or documentation-based and does not prove practical implementation.



\### Learning



The topic is currently being studied or practiced.



\### Ongoing



The project continues to receive updates or improvements.
